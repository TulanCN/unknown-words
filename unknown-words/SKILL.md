# Domain Primer

学习者跨入新领域,障碍不是学不会词——多数词听过一次就懂——而是 unknown-unknowns:不知道这些词存在,连提问的入口都没有。这个 skill 是引路人:在进入领域的入口处,把词汇地图一次铺开。

## 产物:地图,不是词典

一份**词汇地图**,衡量标准是**一遍铺全**:

- 读者读完,知道领域里的词分成哪几组、每个词大概指什么;读代码、读 agent 回复时不被生词拦住;发命令时用得上行话。
- **求全优先于求精**:低频词一句话也要列——那正是 unknown-unknowns 的解药;列出来的每个词,必须是读者未来几周真实会碰到的。
- 深度交给追问:一词一句话就够,这是地图,读者指着某个词追问时再展开(或转 `teach` skill)。

## 分档:接到请求的第一个动作

看请求对象,不看措辞:

- **单个词/单点**("这个词叫什么""这个报错什么意思")→ **快答**:检索作答。已有地图就把词补进去(高频按三件套,低频一句话);没有地图不建图。
- **领域/角色/接手整套**("我要开始写前端了""接手 K8s 运维")→ **全图**:读 [`FULL-MAP.md`](FULL-MAP.md),照它的 checklist 走完摸底、校验、成图、交付。
- **一份具体产物**("帮我看看这个 docker-compose 在干嘛")→ 按快答逐词扫那份产物;用户表达"想系统搞懂这块"再升全图。
- 拿不准默认快答——升档成本低于降档。

## 每词三件套(高频、中频用)

```markdown
### Modal(模态框 / 弹窗)
弹窗的一种:弹出来后盖住整页,不点掉就没法干别的。
遇到:点"删除"后跳出来的确认框,背景变暗那种。
下命令:"做个删除确认弹窗" / "用 modal"。
出处:MDN dialog 文档(2026-08 查证)。
```

三行各管一件事:**人话定义**(不循环定义,不用行话解释行话,对照物织进这行,如 "state ≈ 组件自己的实例字段,一变界面就重画")、**对号入座**(什么长相/什么场景/什么时机遇到)、**怎么用**(一句可直接抄的命令例句)。**出处**行仅高频词必带。按目的调三行权重:发命令 → "怎么用"行最重;读代码 → "对号入座"行最重;面试汇报 → "人话定义"行加"跟外行解释"变体。

**前置标注(可选)**:词块末行写 `前置: A, B`,值为被引用词的**主名**(`###` 标题括号前的部分,如 `### Modal(模态框)` 写 `前置: Modal`),表达"学它之前先学这些"。默认树状图渲染消费它画出依赖分层与学习顺序;不写则不产生依赖(按组和频率排)。**尽量给词挂上下游**:平行词之间不连,但能挂真实上游锚点的都要挂(如组件族词 `前置: 组件`)——渲染器逐次报独立词占比,`###` 词块超 1/3 会告警。允许跨组引用;引用未命中或成环会被丢弃并在 stderr 告警,不阻塞渲染。仅 `###` 词块支持,列表式词不写(留在独立带属正常)。

**深挖途径**:渲染出的词卡带「⧉ 复制追问提示词」按钮,点击把该词的追问提示词复制到剪贴板(页面不显示提示词文本),粘进任意 agent 会话即可追问(或转 `teach` skill)。

**自测(Quiz)**:默认树状图页按 <kbd>Q</kbd>(或报头「Q·自测」按钮)直接进全屏出题评分:从三件套自动出选择题(题干按 定义→场景→命令 取线索,泄漏答案的线索跳过;干扰项取同组/同频率词),键盘 1-4 作答、即时对错上色,答完出分 + 错题回顾。一轮 10 题(词库 ≤10 全出),按前置拓扑序分层取样;**答错过的词下一轮优先再现**(评级存浏览器 localStorage);重置按钮连评级一起清;Esc / ✕ 关闭回树图。

## 分层

- **高频·发命令离不开**:三件套全给。
- **中频·读到要认识**:三件套可砍成两行。
- **低频·知道存在**:一句话 + 什么时候会碰到。
